# Release Builds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Versioned GitHub Releases with Windows and Linux packages built in CI, a local script for the macOS package, and the version shown in the app.

**Architecture:** release-please cuts versions from conventional commits; `release.yml` builds packages with `fyne package` on GitHub runners when a release is created; `scripts/release-macos.sh` does the same on the maintainer's Mac and uploads the `.dmg`. The app reads its version from Fyne metadata.

**Tech Stack:** Go 1.25, Fyne v2.7.3, fyne.io/tools v1.7.3, GitHub Actions, release-please-action v4, bash, hdiutil.

**Spec:** `docs/superpowers/specs/2026-10-12-releases-design.md` — read it; it lists the `fyne package` facts (absolute `--src`, `--executable kana`, version without `v`, output locations, `Build` rewrite of FyneApp.toml) that every build step relies on.

**Conventions:** `gofmt -l .` empty, `go vet ./...` clean, `go test -count=1 ./...` passing before each commit. Commit messages `type(scope): summary` plus a short prose paragraph; no Co-Authored-By, no AI/assistant/session mentions. The icon (`docs/icon/icon.svg`, `fyne/Icon.png`) already exists in the working tree, approved by the maintainer; Task 2 commits it.

```go
package main

import (
	"strings"

	"fyne.io/fyne/v2"
)

// releasesURL is where packaged builds are published.
const releasesURL = "https://github.com/Comradin/kana/releases"

// versionLabel returns the version to show: "v0.2.0" for a release
// package, "dev" otherwise (go run, go build, or a package without a
// real version).
func versionLabel(meta fyne.AppMetadata) string {
	v := strings.TrimPrefix(meta.Version, "v")
	if !meta.Release || v == "" || v == "0.0.0" {
		return "dev"
	}
	return "v" + v
}

// windowTitle is the main window's title, e.g. "Kana v0.2.0".
func windowTitle(meta fyne.AppMetadata) string {
	return "Kana " + versionLabel(meta)
}
```
